# حفظ الإنجليزي (English Trainer)

تطبيق ويب بسيط لحفظ كلمات وجمل الإنجليزي، مقسّم حسب الصف الدراسي (1 إعدادي ← 3 ثانوي).

## المميزات
- كلمات وجمل: تظهر ← تختفي ← تكتبها ← أخضر لو صح، أحمر لو غلط وترجع تحاول.
- زر مساعدة (مرتين لكل كلمة/جملة).
- كيبورد داخلي بدون اقتراحات.
- نطق بالصوت (Text-to-Speech) من المتصفح.
- إضافة كلمات وجمل بنفسك، والتقدم محفوظ على الجهاز (localStorage).

## النشر على GitHub Pages
1. أنشئ Repository جديد (مثلاً `english-trainer`) واجعله Public.
2. ارفع الملفين `index.html` و `README.md` (Add file ← Upload files).
3. من Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` ومجلد `/ (root)` ← Save.
4. بعد دقيقة أو اتنين الرابط يشتغل: `https://USERNAME.github.io/english-trainer/`

## تعديل المحتوى
الكلمات والجمل جوه `index.html` في المتغير `D` (بالشكل `["english","عربي","رقم الوحدة"]`).
لكل صف مفتاح: `g7` (1 إعدادي) ... `g12` (3 ثانوي)، وفيه `w` للكلمات و `s` للجمل.

## ملاحظات
- الصوت يحتاج Chrome وSpeech Services by Google مثبتة على أندرويد.
- التقدم والكلمات المضافة بتتخزن في المتصفح، فمتتنقلش بين الأجهزة.
